1.What is a function?
A function is a reusable block of code designed to perform a specific task .you define it once and can run it whenever you need it.


2.Why do we use functions?
avoid repetation: write code once ,use it multiple times. 
breaks large program into small readable chunks.organization
easy fixing:if something is broken you only need to fix inside it.

3.Difference between parameters and arguments.
parameters are the place holder in the function defination (eg: x and y in def add(x, y):)
arguements are the actual values you pass into the function when you call it (eg: 5 and 10 in add(5, 10))


4.What is return?
the return statement exits a function and sends a value back to where the function was called, allowing the program to save it in a variable or use it in further code.

5.Difference between print() and return.
print() just displays text on the screen for a human to see. The computer cannot use that output for any further math or logic.

return hands over the actual data to the program so the computer can store it, modify it, or use it later.
