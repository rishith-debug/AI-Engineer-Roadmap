Q: What is a module in Python?

Answer: A module is a Python file containing reusable code such as functions, classes, and variables.

Q: Why do we use import?

Answer: import allows us to use code from another module in our program.
Q: What is the difference between import math and from math import sqrt?

Answer:
import math imports the module, so you access sqrt as math.sqrt().

from math import sqrt imports only the sqrt function, so you can call it directly as sqrt().

Q: Can you import multiple functions from the same module?

Answer: Yes. Separate the function names with commas:

from math import sqrt, factorial

Q: What does random.randint(a, b) do?

Answer: It returns a random integer between a and b, including both endpoints.

Q: What is datetime used for?

Answer: It provides classes and functions for working with dates and times in Python.

Q: What does datetime.datetime.now() return?

Answer: It returns the current local date and time as a datetime object.
